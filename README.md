# The Growth of AI - Landing Page

A modern Next.js landing page exploring the exponential growth of Artificial Intelligence in recent years.

## Features

- Built with **Next.js 14** for optimal performance
- **TypeScript** support for type safety
- **Responsive design** that works on all devices
- **CSS styling** with a modern tech-inspired color scheme
- Showcases AI milestones and achievements

## Getting Started

### Prerequisites
- Node.js 18.17 or later

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Production Build

```bash
npm run build
npm run start
```
